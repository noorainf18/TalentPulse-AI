FEATURES

One surface for evidence-led technical hiring

TalentPlus AI turns unstructured resumes into structured profiles, runs a LangGraph screening agent against real GitHub signal, and serves everything in a secure recruiter workspace — including a RAG chat that only answers from your data.

PDFs are normalized with Docling, then Claude fills a strict JSON schema. Every field you care about — skills, roles, projects, education — lands in Postgres and is chunked for Chroma so search and GPT stay aligned with the source resume.

Docling + pdf pipeline

Layout-aware extraction, hyperlink preservation for evidence URLs, deterministic markdown for tracing.

Structured outputs

Typed schema for downstream scoring; fewer surprises when the agent reads candidate facts.

Vector memory

Embeddings per resume power TalentPlus GPT and hybrid retrieval without copying data to a third-party store.

A multi-node LangGraph orchestrates research, scoring, gap analysis, and fit decisions. GitHub is queried as a first-class evidence source; Celery runs the graph asynchronously so your dashboard stays responsive.

LangGraph control flow

Explicit nodes and edges replace fragile prompt chains — easy to audit and extend.

GitHub evidence

Async workers

HOW IT WORKS

How TalentPlus AI runs end-to-end

In one sentence: you upload a PDF once; we extract structured candidate data, enrich it with GitHub and vector memory, run an auditable LangGraph screening job, and drop ranked, evidence-linked profiles into your dashboard and TalentPlus GPT.

There is no manual copy-paste between tools. Sessions keep recruiters isolated per workspace, and every automated decision carries a trace you can open in the UI. The five stages below mirror the actual production pipeline — from file intake to conversational search over your pool.

01

Upload PDF

Drop any resume — PDFs are extracted via Docling, normalized to markdown, and hyperlinks are captured for evidence mapping.

Docling + pdfplumber
02

Structured Extraction

Claude parses name, email, skills, experience, projects, and education into a typed JSON schema — ready for DB storage and scoring.

Anthropic structured outputs
03

LangGraph Agent Screening

A multi-node graph runs: GitHub research → skill scoring → gap analysis → fit decision → trace logging. Fully async via Celery.

LangGraph + Celery + GitHub API
04

Evidence Dashboard

Review the full candidate: profile, GitHub evidence, gap analysis, agent trace, and recruiter feedback tabs — all in one secure view.

Django REST + Next.js SPA
05

TalentPlus GPT Chat

Ask natural language questions across your whole candidate pool. RAG retrieves from Chroma vectors; Claude synthesizes ranked answers.

Chroma RAG + Anthropic

Pricing questions

Is screening priced per resume?

No. Starter includes 25 screens a month. Growth and Enterprise do not charge per candidate.

What is a voice interview?

After a candidate clears the screen, TalentPlus can run a LiveKit interview and write the score back to the profile. It is included on Growth and Enterprise.

Where does the resume data live?

Each workspace is session-isolated. Enterprise can run the stack in your VPC or on-prem if the data cannot leave your network.
